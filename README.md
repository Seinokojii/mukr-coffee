# МУКР Кофе — бонусная карта

Бонусная программа кофейни МУКР: у каждого ученика своя регистрация, профиль и личный QR-код.

- **10 баллов** за любой стакан (маленький 140 сом, большой 170 сом)
- **60 баллов** — бесплатный кофе на выбор, баллы списываются
- баллы хранятся на сервере, а не в телефоне

Сайт: https://seinokojii.github.io/mukr-coffee/

## Как устроено

| Часть | Где |
|---|---|
| Страница (`index.html`, `app.css`, `app.js`) | GitHub Pages |
| API и база (`server.py`, SQLite) | VPS, https://mukrcoffee.62-113-109-193.sslip.io |

`server.py` — один файл на стандартной библиотеке Python. Он же отдаёт страницу, так что адрес на VPS работает и сам по себе.

**Ученик:** регистрируется по телефону → видит QR, штампы и историю. Новый штамп появляется сам, как только бариста отсканировал код.

**Бариста:** входит по логину → сканирует QR камерой (или вводит 8-значный код) → «Маленький +10», «Большой +10» или «Бесплатный −60». Ошибочную операцию можно отменить в течение 10 минут. Внизу — итоги дня.

## Команды на сервере

```bash
python3 server.py --staff <логин> "<Имя>" [пароль]   # завести бариста
python3 server.py --reset <телефон|логин> [пароль]    # сменить забытый пароль
```

Правила (баллы за стакан, цена бесплатного, цены) — константы в начале `server.py`.

Выкладка сервера: `./publish.sh`. Страница на Pages обновляется после `git push`.
